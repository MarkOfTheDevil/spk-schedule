| --- | --- | --- |

Оригинальные APK промежуточных выпусков сейчас недоступны. При получении этих файлов их можно проверить тем же скриптом и добавить сюда. Современная сборка не выдаётся за старую.

Ключ подписи у всех APK совпадает с актуальным приложением. Суммы SHA-256 хранятся рядом с каждой сборкой. Эти версии импортированы в GitHub позднее их создания; дата выпуска на GitHub означает дату импорта.

Автоматические архивы Source code в исторических GitHub Releases относятся к коммиту импорта. Они не являются исходниками старых бинарных сборок.
