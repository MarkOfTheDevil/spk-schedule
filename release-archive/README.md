Ключ подписи у всех APK совпадает с актуальным приложением. Суммы SHA-256 хранятся рядом с каждой сборкой. Файлы сохранены без изменения содержимого; современные исходники не пересобирались под старыми номерами.

Эти версии импортированы в GitHub позднее их создания; дата выпуска на GitHub означает дату импорта. При добавлении архива актуальной остаётся 1.13.0.

Автоматические архивы Source code в исторических GitHub Releases относятся к коммиту импорта. Они не являются исходниками старых бинарных сборок. Отдельно переданные архивы проекта находятся в [archives/](../archives/README.md).
