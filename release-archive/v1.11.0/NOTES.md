Обновления приложения через GitHub Releases: проверка версии, скачивание APK с прогрессом и установка после подтверждения Android. Сохраняются темы, избранное, расписание, напоминания и виджеты.

Переход с 1.10.0 и более старых версий: один раз скачайте APK этого выпуска и установите поверх приложения, не удаляя его. Следующие обновления будут доступны внутри приложения.
