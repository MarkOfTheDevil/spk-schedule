# Сигнал Pulse для уведомлений Android

Здесь подготовлен код для подключения утверждённого звука к Android-проекту Pulse 2.0. Контрольная база — выпущенное приложение `ru.spk.schedule` версии 1.16.0.

1. Поместить `assets/notifications/pulse_notification.wav` в `app/src/main/res/raw/pulse_notification.wav`. Поместить `PulseReminderChannel.java` рядом с нативным `ReminderScheduler`.
2. Сохранить создание существующего канала `tomorrow_classes_v1`. В `ReminderScheduler.base(Context, PendingIntent)` передавать в `Notification.Builder` идентификатор из `PulseReminderChannel.select(context, usePulseSound, R.raw.pulse_notification)`. Флаг `usePulseSound` должен отражать выбор пользователя. Установкам, у которых уже есть прежний канал, предложить фирменный звук явно, чтобы не менять звук уведомлений без согласия. Обычное и тестовое напоминания должны использовать одну настройку. Служебное уведомление `schedule_update_v1` остаётся в своём канале.
3. При проверке на устройстве проверить обычное и тестовое напоминания, сводку из нескольких карточек, открытие правильных группы и даты по нажатию, тихий режим и установку поверх 1.16.0. Убедиться, что СПК и ЦРК сохраняют последнюю успешную загрузку отдельно. Для проверки расхождений между Android и PWA использовать случай группы Д193/1 из чата «Загрузка сайта на GitHub Pages» и записывать, какой источник и какая дата снимка показаны в каждом клиенте.

Класс компилируется с Android SDK API 35. Подключение в проекте и проверка звучания системного уведомления на телефоне ещё предстоят.
