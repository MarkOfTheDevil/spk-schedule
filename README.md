# Расписание СПК — Android

Репозиторий готовых подписанных APK и автоматической публикации обновлений.

**[Скачать актуальную версию](https://github.com/MarkOfTheDevil/spk-schedule/releases/latest)** · **[Все выпуски](https://github.com/MarkOfTheDevil/spk-schedule/releases)**

## Новое в 1.15.0

Исправлена повторная проблема обновления ЦРК. Новые записи без группы и апострофы в кодах больше не блокируют чтение всей таблицы. Неприкреплённые записи доступны отдельно под расписанием, сомнительный формат отмечается предупреждением. Кабинеты определяются по заголовкам. Встроенная копия обновлена: 22 группы, проверены обе недели. При недоступности сайта или повреждённом файле сохраняется предыдущая копия; приложение показывает реальный результат обновления СПК и ЦРК отдельно.

Подгруппы отключены по умолчанию в приложении, отправке, уведомлениях и виджете. Если они вернутся в колледже, включите «Настройки → Параметры расписания → Учитывать подгруппы». Прежний выбор сохранён.

В настройках убраны общая шапка, переключатель СПК/ЦРК и поиск. Из предпросмотра отправки удалён блок «Расписание текстом»; сама отправка текстом сохранена.

Конструктор приложения получил цвета карточек, основного и второстепенного текста, точные отступы, интервалы, скругления и толщину рамок, размеры/насыщенность заголовков, межстрочный интервал, направление/интенсивность/скорость градиента. Параметры доступны в «Точная настройка»; цвета для светлой и тёмной темы сохраняются отдельно.

## Сохранено из 1.14.0

Конструктор **самого приложения**: Настройки → Оформление → Конструктор приложения. Выберите палитру-основу, свой фон и два акцентных цвета, мягкий или выразительный градиент, скругление карточек, отступы, размер текста и обычные/точечные заголовки. Цвета для светлого и тёмного режима сохраняются отдельно, системное переключение работает. Изменения видны сразу; «Сохранить» подтверждает их, «Отмена» возвращает прежний вид. Доступен сброс к исходной палитре.

Поиск получил компактную карточку «Параметры поиска» по новому образцу: категория, СПК/ЦРК, избранное, сброс и «Применить» с количеством результатов. Панель и список прокручиваются вместе; длинный список больше не сжимает фильтр до одних кнопок. Запрос сохраняется, неподтверждённые параметры можно отменить.

В выпуск входят функции предыдущей версии: **каждый день недели отдельным PNG**, подписи продолжения для длинного дня, **конструктор картинок** в «Поделиться → Оформить картинку», текстовая отправка и ссылки. Картинки имеют ширину 1080 px; для исходного качества в мессенджере выбирайте отправку файлом, если этот режим доступен.

Сохранены единый поиск групп, преподавателей, предметов и кабинетов в СПК и ЦРК, календарь месяца, переходы свайпом, 30 цветовых схем, плавные анимации, тактильный отклик, избранное, уведомления и прокручиваемый виджет с выбором даты. Виджет использует базовую палитру приложения; конструктор меняет интерфейс приложения.

Ссылки требуют Android-приложения 1.13+; их можно вставить в умный поиск. Картинки и текст доступны без приложения. Календарь использует текущую таблицу колледжа: будущие замены и праздники могут ещё не учитываться.

## Установка и обновления

Скачайте APK из Assets нужного выпуска и установите его на Android 8.0 или новее. Для обновления сохраните установленное приложение: APK устанавливается поверх него, настройки и избранное остаются.

**1.11.0** переводит проверку и скачивание обновлений на GitHub Releases. Один раз установите её вручную поверх 1.10.0 или более ранней версии. Следующие выпуски приложение увидит само: появится плашка, кнопка скачивания и установка с подтверждением Android. Ручная проверка — «Настройки → О приложении → Проверить обновления».

Проверка при запуске и возвращении в приложение выполняется не чаще раза в 6 часов. Установленная актуальная версия не показывает обновление на саму себя. При отсутствии интернета сохраняется расписание; ошибка проверки не выдаётся за подтверждение актуальности.

## Автоматическая публикация

Подписанный APK подготавливается скриптом `tools/prepare_release.py`. Коммит каталога `release/` в `main` запускает **Publish signed Android releases**. GitHub Actions проверяет подпись, размер и контрольную сумму, прикрепляет APK и метаданные к черновику и публикует полный выпуск. Приложение получает обновление только после публикации.

APK собирается разработчиком с прежним ключом подписи. Этот репозиторий хранит готовые установщики и сценарии публикации. Актуальный Android-проект и приватный ключ хранятся отдельно. Переданные владельцем исторические ZIP с Android-исходниками 1.3.0 и веб-приложением сохранены в [archives/](archives/README.md).

Инструкция: [ANDROID-UPDATES.md](ANDROID-UPDATES.md). Архив: [release-archive/README.md](release-archive/README.md).

## Архив

Сохранена **21 оригинальная сборка от 1.0.0 до 1.14.1**, включая промежуточные выпуски 1.3.1, 1.4.1, 1.5.1 и 1.9.1. Вместе с актуальной 1.15.0 доступны 22 версии. Подпись каждого APK проверена; контрольные суммы находятся рядом с файлами. Дата исторического GitHub Release означает дату импорта.

Для установки скачивайте **файл .apk**. Автоматические Source code ZIP/TAR — это снимки данного репозитория на момент импорта, а не исходники соответствующей версии Android-приложения. Отдельно переданные исходные архивы описаны в [archives/README.md](archives/README.md).
