# Расписание СПК — Android 1.11.0

Расписание Северского промышленного колледжа: группы и подгруппы, чётные/нечётные недели, преподаватели, избранное, темы, уведомления и виджеты. Android 8.0+.

**[Скачать актуальный APK](https://github.com/MarkOfTheDevil/spk-schedule/releases/latest)** · **[Все выпуски](https://github.com/MarkOfTheDevil/spk-schedule/releases)**

## Обновления из репозитория

Начиная с 1.11.0 приложение проверяет GitHub Releases. При появлении новой версии оно показывает плашку, скачивает APK с прогрессом и открывает системный установщик после нажатия «Установить». Проверяются размер, SHA-256, имя пакета, версия Android и оригинальная подпись APK.

- Автоматическая проверка при открытии и возвращении в приложение — не чаще раза в 6 часов.
- Ручная проверка: «Настройки → О приложении → Проверить обновления».
- «Позже» скрывает плашку этой версии на сутки. Скачивание можно отменить и повторить.
- Офлайн остаются расписание и сведения о последней известной версии; сетевая ошибка не выдаётся за подтверждение актуальности.
- Установка требует подтверждения Android. При необходимости разрешите установку для «Расписание СПК», вернитесь и снова нажмите «Установить».
- Cloudflare используется отдельно для веб-приложения; Android APK публикуются в этом репозитории.

**Переход с 1.10.0 и более ранних сборок:** один раз скачайте актуальный APK из Releases и установите поверх старого приложения, не удаляя его. Ключ подписи сохранён, настройки и избранное остаются. Установленная 1.11.0 не должна предлагать обновление на саму себя.

## Выпуск новой версии

APK собирается и подписывается на машине с приватным ключом. `tools/prepare_release.py` создаёт каталог `release/` с APK, описанием и контрольной суммой. После отправки этого каталога в `main` GitHub Actions автоматически проверяет пакет и публикует GitHub Release. APK и метаданные сначала прикрепляются к черновику и становятся видимыми приложению вместе.

Подробная инструкция — [ANDROID-UPDATES.md](ANDROID-UPDATES.md). Сведения о найденных старых сборках — [release-archive/README.md](release-archive/README.md).

## Окно «О приложении» и свайпы в 1.9.1

В **«Настройки» → «О приложении»** собраны восемь раскрываемых разделов: расписание и свайпы, преподаватели и избранное, «Сейчас и далее», изменения расписания, уведомления на завтра, виджет, оформление и тактильный отклик, обновление и работа без интернета. Инструкции по виджету и изменениям больше не занимают отдельные карточки в настройках. Функции продолжают работать как прежде.

Текст окна прокручивается, кнопка закрытия и «Понятно» остаются доступны. Окно закрывается также касанием затемнённого фона, Escape или системной кнопкой «Назад», возвращая фокус к кнопке открытия.

При свайпе список с заголовком, временем и карточками движется внутри неподвижной ограниченной области. Сдвиг сокращён с 44 до 20 px, края мягко затухают, новое расписание появляется из полностью прозрачного состояния. Исчезновение занимает 170 мс, появление — 420 мс. Направление соответствует жесту; скользящее выделение дня сохранено. При отключении анимаций или системном уменьшении движения переход мгновенный. Обычные нажатия сохраняют поочерёдное появление пар.

## Выделение изменений расписания

После первого открытия версии 1.9.0 приложение запоминает показанное расписание. При последующих обновлениях сравниваются предмет, преподаватель, кабинет, время и состав подгрупп. Изменение даты загрузки, порядка строк или технических полей таблицы само по себе не создаёт отметок.

- **Добавлено** — появилась новая пара или занятие выбранной подгруппы.
- **Изменено** — у существующей пары изменились данные. Разверните «Что изменилось», чтобы увидеть «Было» и «Стало».
- **Убрано** — занятие отсутствует в новой версии таблицы. Оно показано отдельно и не входит в число текущих пар. Это описание изменения файла, а не отдельное подтверждение отмены занятия колледжем.
- Точки на днях отмечают изменения выбранной недели и подгруппы. Кнопка «К изменениям» открывает подходящий день; если изменения только в другой чётности, переключает и неделю.
- Отметки сохраняются после перезапуска и повторных загрузок одинакового расписания. «Понятно» убирает отметки выбранного расписания. При новом изменении отметки появятся снова. Если данные вернулись к первоначальному непросмотренному варианту, отметка исчезает.
- Подсветка действует в расписаниях групп и преподавателей. Изменения другой подгруппы не подсвечиваются; общие пары учитываются для обеих подгрупп.
- Сравнение доступно в приложении. Виджет продолжает показывать актуальные ближайшие пары без истории изменений. Отдельные объявления колледжа о заменах не входят в источник XLSX.

История хранится на телефоне; сервер и регистрация не нужны. При очистке данных приложения отслеживание начинается заново.

## Свайпы по дням

Свайп влево выбирает следующий день, вправо — предыдущий. Жест действует по занятиям, полосе дней, заголовкам и свободным участкам расписания. Переход движется горизонтально в сторону жеста. Обычные нажатия на дни и вертикальная прокрутка доступны; системный жест от края экрана, диалоги, поля ввода и другие кнопки не перехватываются. Границы понедельника и воскресенья сохранены: свайп не меняет неделю сам.

## Виджет на главный экран

Зажмите свободное место на главном экране Android → **Виджеты** → **Расписание СПК — ближайшие пары**. Перетащите виджет на экран и выберите группу, подгруппу и тему. Названия пунктов могут немного отличаться у разных производителей.

- Виджет показывает время начала и конца, предмет и кабинет. Завершившиеся пары исключаются при следующем обновлении. После последних пар он находит следующий учебный день, учитывая чётность недели и выбранную подгруппу.
- Размер можно менять: компактный виджет показывает одну пару, средний — две, большой — три. Если занятий больше, внизу указано их число. Нажмите на виджет, чтобы открыть все занятия нужной группы, дня и чётности в приложении.
- Каждый виджет сохраняет свою группу независимо от текущей группы в приложении. Можно разместить несколько виджетов.
- Кнопка настроек меняет группу, подгруппу и яркость. Режим «Как в приложении» учитывает тему приложения; цветовая палитра общая. Неоновые схемы используют мягкий градиент по всей поверхности.
- Круговые стрелки запрашивают загрузку свежего расписания. При отсутствии сети или ошибке сайта сохранённые данные остаются на экране.
- Автообновление запрашивается примерно раз в 30 минут; Android может задерживать его из-за ограничений батареи. Это снимок на момент, указанный после «На», а не непрерывный отсчёт. Отдельно указана дата сохранения расписания. После смены системной темы оформление виджета пересчитывается при его следующем обновлении или открытии приложения.
- Разрешение на уведомления и точные будильники для виджета не требуется. На телефонах с агрессивным энергосбережением фоновое обновление может ждать запуска приложения или ручного обновления.

## Возможности

- Виджет ближайших пар с отдельной группой и подгруппой, изменением размера и фоновым обновлением.
- Поиск и выбор любой из 53 групп в исходном файле. Названия объединённых групп сохраняются как в таблице.
- Вкладка «Преподаватели»: поиск среди 84 преподавателей, просмотр занятий во всех группах и быстрый переход к расписанию нужной группы.
- Подсветка новых, изменённых и убранных пар, сравнение «Было / Стало», сохранение отметок до просмотра.
- Дни недели с понедельника по воскресенье, выбор кнопкой или свайпом по занятиям.
- «Сейчас и далее»: текущая пара, отсчёт до её конца, следующая пара и кабинет. До начала занятий и на перемене — время до следующей пары.
- Чётная и нечётная недели, обе подгруппы или одна выбранная.
- Время начала и окончания пары, предмет, преподаватель и аудитория.
- Несколько избранных групп, запоминание последней группы и подгруппы для каждой группы.
- Светлая, тёмная и системная темы. 24 цветовые палитры, включая 8 неоновых, каждая в светлом и тёмном варианте. Быстрое переключение яркости в верхней панели.
- Скользящее выделение подгруппы, недели и дня, поочерёдное появление пар слева, анимации нажатий и переливание неоновых градиентов. Отдельный выключатель и учёт системного уменьшения движения.
- Тактильный отклик при касаниях, с отдельным выключателем в настройках и учётом системной вибрации при касании.
- Автоматическое обновление при открытии, кнопка обновления, просмотр сохранённой версии без интернета.
- Отключаемые вечерние уведомления: сначала обновление расписания, затем пары на завтра для выбранной группы и подгруппы.
- Общие объявления перед первой парой в понедельник — в раскрывающемся блоке.

## Свайпы и «Сейчас и далее» в 1.8.0

Смахните по области занятий влево, чтобы открыть следующий день, или вправо — предыдущий. Переключение работает в пределах выбранной недели: после воскресенья и перед понедельником перехода нет. Подсветка дня скользит к выбранной кнопке. При свайпе список перемещается горизонтально внутри ограниченной области, а при нажатии пары появляются по очереди слева. Свайпы работают и в расписании преподавателя, и на пустом дне. Обычная вертикальная прокрутка, масштабирование двумя пальцами, кнопки и жесты от края экрана не переключают день. При успешном переключении используется установленная настройка тактильного отклика. Для возврата к текущему дню есть кнопка «Сегодня»; в ручном режиме недели — «Сейчас».

Блок «Сейчас и далее» появляется в автоматическом режиме на сегодняшнем дне. Он использует время телефона и выбранную подгруппу. Во время пары показывает предмет, кабинет, оставшееся время и шкалу прошедшего времени. Ниже — следующая пара и время её начала. До первой пары и во время перемены показывается отсчёт до занятия. После последней пары — сообщение о завершении дня; если занятий нет — «Сегодня без пар». В расписании преподавателя также указаны группы. Для ручного просмотра другой чётности отсчёт скрыт, чтобы не выдавать условное расписание за текущее.

Отсчёт обновляется раз в минуту, включая моменты начала и конца пары. Меняются только сведения о времени и выделение текущей карточки: весь список не заменяется, фокус не сбрасывается и анимации появления не повторяются. Таймер приостанавливается в фоне и пересчитывает время при возвращении. При смене даты в автоматическом режиме выбирается сегодняшний день и пересчитывается чётность недели. Сервер или новые разрешения Android не требуются.

## Цветовые схемы

Откройте **«Настройки» → «Оформление» → «Цветовая схема»** и нажмите на текущую палитру. Сохранены 16 классических вариантов: Мята, Океан, Небо, Бирюза, Ирис, Лаванда, Слива, Роза, Вишня, Персик, Янтарь, Лайм, Лес, Олива, Кофе и Графит.

Карточки показывают миниатюру каждой схемы. Нажатие сразу применяет её и сохраняет выбор; окно остаётся открытым для сравнения. Нажмите «Готово», крестик или системную кнопку «Назад», чтобы вернуться к настройкам.

Палитра меняет фон, карточки, кнопки, текст, значки, выделение выбранного дня и цвета системных панелей Android. У каждой схемы есть светлый и тёмный вариант — всего 48 сочетаний. Режим «Как в системе» автоматически переключает яркость выбранной палитры. Палитра сохраняется при смене светлой/тёмной темы и перезапуске приложения. Быстрая кнопка вверху переключает яркость, оставляя выбранные цвета.

При первом запуске используется «Мята». При обновлении сохраняются выбранная палитра, группы, избранное, преподаватель, подгруппы и настройки уведомлений. Схемы встроены в APK и доступны без интернета.

### Новые неоновые схемы в 1.4.0

В выборе схем есть фильтры **«Все»**, **«Классика»** и **«Неон»**. В неоновой подборке: **Неон-сити, Киберпанк, Ультрафиолет, Токио, Лазер, Матрица, Кислотный лайм, Плазма**. Начиная с версии 1.4.1, плавный градиент заполняет всю карточку группы, активные кнопки и выбранный день. Карточки занятий имеют более мягкий переход между оттенками. Тонкая градиентная полоска удалена. Миниатюры палитр показывают новое оформление. В версии 1.5.0 градиенты главной карточки, выбранного дня и основных кнопок медленно переливаются; градиенты карточек занятий остаются статичными для чтения. Основной текст остаётся без свечения. При переходе к классической палитре неоновые эффекты исчезают. Автоматическая системная тема и прежние настройки сохраняются.

## Скользящие переключатели и появление пар в 1.6.0

Откройте **«Настройки» → «Оформление» → «Плавные анимации»**. По умолчанию они включены; выбор сохраняется после перезапуска.

Выделение подгруппы, чётности недели и дня скользит к выбранной кнопке вправо или влево за 460 мс. Сами кнопки, карточка группы и верхняя часть расписания остаются на месте и не исчезают. При повторном выборе во время движения подсветка продолжает путь с текущей позиции. Активная кнопка и доступность для клавиатуры обновляются сразу. При повороте телефона подсветка подстраивается под размер кнопок.

После короткого исчезновения прежнего списка новые пары по очереди въезжают слева. Движение одной карточки длится 500 мс, интервал между началами — 75 мс. Время, предмет, преподаватель и аудитория движутся вместе с карточкой. Тот же порядок применяется к расписанию преподавателя и при выборе новой группы. Сообщение «Занятий нет» также появляется слева. Фоновые обновления не запускают эти анимации повторно. Повторные быстрые нажатия оставляют последнее выбранное расписание.

Режимы автоматической и ручной недели больше не добавляют строку между переключателями: ручной режим отмечен названием недели под заголовком дня, а кнопка «Сейчас» возвращает текущую дату. Благодаря этому дни не сдвигаются вниз при выборе чётности.

В неоновых схемах движется отдельный слой градиента главной карточки и основных кнопок. При сворачивании приложения движение приостанавливается. Цвета скользящих выделений соответствуют выбранной палитре. Настройка уменьшения движения в Android/WebView имеет приоритет над переключателем приложения. При отключении анимаций выделение и занятия меняются сразу. Окна выбора группы и палитры сохраняют плавное открытие и закрытие.

## Тактильный отклик

Откройте **«Настройки» → «Тактильный отклик»**. По умолчанию отклик включён. Короткие сигналы сопровождают выбор дня, недели, группы, преподавателя, подгруппы, темы, переход между разделами и добавление в избранное. Уже выбранные дни и темы повторно не вибрируют; обновление в фоне и ввод текста не создают отклика. При отключении функция остаётся выключенной после перезапуска.

Используется нативный `View.performHapticFeedback`: Android учитывает свою настройку вибрации при касании и возможности устройства. Дополнительное разрешение на вибрацию не требуется. Если вибрация касаний выключена в Android или устройство не поддерживает её, отклика не будет даже при включённом переключателе приложения. Настройка не меняет звуки и вибрацию уведомлений. При включении переключателя подаётся короткое подтверждение, при выключении отклика нет.

## Уведомления «Пары на завтра»

1. Откройте «Настройки» → «Пары на завтра», выберите группу, подгруппу и время. По умолчанию — 20:00 по местному времени телефона.
2. Если видна кнопка «Разрешить точное время», нажмите её и разрешите доступ «Будильники и напоминания» в Android.
3. Включите переключатель; на Android 13 и новее разрешите показ уведомлений в системном запросе. Проверьте строку «Следующее уведомление» с фактической датой и временем.
4. Нажмите «Проверить через минуту», затем закройте приложение и дождитесь проверки. Этот отдельный таймер не изменяет ежедневное время.
5. Кнопка «Показать сейчас» позволяет сразу проверить обновление и содержимое уведомления.

Точный таймер запускает короткую foreground service прямо из обработчика AlarmManager. Промежуточная очередь JobScheduler удалена. Пока обновляется XLSX, Android показывает тихий индикатор «Обновляем расписание». После загрузки, разбора и сохранения появляется расписание. Если обновление не закончится за восемь секунд или завершится ошибкой, отправляется сохранённая версия с явной пометкой. Служба и индикатор после этого останавливаются. При отказе Android в запуске службы обработчик выполняет ограниченную семью секундами попытку обновления и затем отправляет результат или сохранённые данные.

Без разрешений на показ уведомлений и точное время ежедневный таймер приостанавливается; причина видна в настройках. После предоставления доступа и возврата в приложение таймер восстанавливается. Перезагрузка, установка обновления, изменение часов или часового пояса также восстанавливают ежедневный таймер. Одноразовая проверка после таких событий отменяется. Повторное изменение времени в тот же день создаёт новый запуск, а отменённая загрузка не присылает уведомление после отключения функции.

В настройках показаны следующий ежедневный запуск, время проверки и результат последней попытки. В блоке «Если уведомление не пришло» есть переход в системные настройки. Проверьте разрешение уведомлений и доступ к точному времени; при ограничениях фоновой работы выберите для приложения режим батареи без ограничений. После принудительной остановки через настройки Android приложение нужно открыть снова. Ограничения производителя телефона и принудительную остановку приложение не может отменить само.

### Все пары в уведомлении

В версии 1.3.1 длинный многострочный блок заменён группой уведомлений. В сводке показаны количество пар, диапазон времени и компактный список. Раскройте группу: каждая пара имеет свою карточку с номером, временем, предметом, аудиторией и нужной подгруппой. Карточки идут по порядку, включая третью, четвёртую и последующие пары; количество не ограничено двумя или шестью строками сводки. Звук подаёт сводка, дочерние карточки не создают отдельную серию звуков.

Высоту сводки и отдельных карточек определяет Android, поэтому на некоторых телефонах часть длинного текста в компактном виде может скрываться. Все пары доступны через раскрытие группы и кнопку «Все пары», открывающую именно дату, группу и подгруппу из уведомления. Если занятий нет, приходит одно сообщение «Занятий нет». Если группа отсутствует в обновлённом файле, приложение явно сообщает об этом.

Группа для уведомлений закреплена отдельно и не меняется при просмотре других групп. Чётность считается для дня занятий, включая переход с воскресенья на понедельник. Сервер рассылки и регистрация не нужны; это локальные уведомления Android.


## Исправления оформления в 1.2.0

Режим «Как в системе» получает тему непосредственно из конфигурации Android и реагирует на её смену, в том числе после возвращения в приложение. Светлая и тёмная темы остаются отдельным ручным выбором. Значок обновления заменён на две соединённые круговые стрелки. Время уведомления отображается полностью в формате `20:00` независимо от формата встроенного браузера.

## Поиск по преподавателям

1. Откройте вкладку «Преподаватели» внизу экрана.
2. Введите фамилию, её часть или фамилию с инициалами. Регистр, пробелы, точки в инициалах и разница между «е» и «ё» не мешают поиску.
3. Выберите преподавателя, затем день и чётность недели.

В каждой паре показаны предмет, время, аудитория, группы и подгруппы. Например, у Полонской А.А. на чётный понедельник есть шесть пар, на нечётный — пять. Преподаватели с одной фамилией и разными инициалами остаются отдельными записями.

Нажатие на группу открывает её расписание на выбранный день и неделю; для отдельной подгруппы включается соответствующий фильтр. Поиск преподавателя не ограничивается ранее выбранной группой. Последний преподаватель запоминается. Данные преподавателей автоматически пересобираются при обновлении расписания и доступны без интернета.

Одновременные записи с одинаковым предметом и аудиторией объединяются в одну карточку с перечнем групп и подгрупп. Разные предметы и аудитории сохраняются отдельными записями в рамках одного времени пары.

## Как работает чётность

Исходная опорная неделя **19–25 октября 2026 года — чётная**, согласно уточнению заказчика. Каждое следующее начало недели в понедельник меняет чётность. Используется местная дата телефона; переход через летнее/зимнее время не влияет на расчёт.

Кнопки «Чётная» и «Нечётная» открывают шаблон выбранной недели без привязки к датам. Кнопка «Сейчас» возвращает автоматическую неделю и сегодняшний день. В настройках можно уточнить чётность текущей недели, например если колледж изменил порядок после каникул.

## Данные и обновление

В APK встроена копия расписания, полученная 24 октября 2026 года по времени Красноярска. Она позволяет открыть приложение даже при первом запуске без сети. Дата сохранения отображается в интерфейсе.

Обновление загружает XLSX прямо с сайта колледжа и разбирает его на телефоне. Сервер приложения, аккаунт, аналитика и реклама отсутствуют. Разрешения: интернет, показ уведомлений, восстановление напоминания после перезагрузки и доступ к точному времени, короткая foreground service для обновления и кратковременное удержание процессора во время загрузки. Разрешение на уведомления запрашивается при включении функции, доступ к точному времени — только по отдельной кнопке.

В текущем файле нижний блок обозначен «ЧЕТНАЯ НЕДЕЛЯ». Верхний блок без подписи интерпретируется как нечётный. Группы определяются по объединённым заголовкам из четырёх столбцов. Повторяющаяся подпись в разделительном столбце не создаёт лишнюю группу. Отличающееся написание `193П/194/2П` в верхнем блоке и `Д193П/Д194/2П` в нижнем сохранено как два поисковых варианта одной группы.

Если сайт недоступен, возвращает HTML вместо XLSX или структура таблицы не распознана, старые данные сохраняются и приложение показывает сообщение. Сохранение обновления выполняется атомарно после успешного разбора. Произвольные изменения формата таблицы в будущем могут потребовать доработки парсера. Файл содержит основное расписание; отдельные объявления о заменах в других источниках не загружаются.

В заголовке указаны два времени «Разговоров о важном» — 08:35 и 08:50 — без однозначной привязки к группе. Приложение показывает их как общее примечание, не выбирая время за пользователя.

## Сборка

Нужны JDK 17, Python 3, Android SDK Platform 35 и Build Tools 35.0.0. Можно импортировать Gradle-проект в Android Studio или собрать из командной строки. Для Gradle 8.9 подходит указанный в проекте Android Gradle Plugin 8.7.3.

В проект включён Gradle Wrapper 8.9. Команда `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`) создаёт отладочную сборку. Для обновления поверх выданного APK потребуется исходный ключ подписи: отладочный ключ отличается. Первой Gradle-сборке нужен интернет для загрузки Gradle и Android Gradle Plugin.

Для сборки через SDK:

```bash
export ANDROID_SDK_ROOT=/absolute/path/to/Android/Sdk
export SPK_KEYSTORE=/absolute/path/to/your-key.jks
export SPK_KEY_ALIAS=your-key-alias
read -s SPK_KEYSTORE_PASSWORD
export SPK_KEYSTORE_PASSWORD
python3 tools/build.py
```

Ключ можно создать командой `keytool -genkeypair`, указав имя файла ключа, псевдоним и срок действия. Пароль лучше вводить интерактивно. Ключ и его пароль не включены в архив исходников. Ключ этой поставки сохранён отдельно в личном архиве `SPK-Raspisanie-signing-private.zip`. Он нужен для будущих обновлений поверх установленной версии; его нельзя публиковать вместе с кодом.

Результат сборки: `output/SPK-Raspisanie-1.11.0.apk`. Скрипт выполняет упаковку, DEX-компиляцию, выравнивание ZIP, подпись и проверку подписи. Если применяется Eclipse ECJ вместо `javac`, укажите абсолютный путь `ECJ_JAR`.
