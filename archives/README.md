# Архивы проекта

Оригинальные ZIP, предоставленные владельцем приложения и добавленные в репозиторий по его запросу. Содержимое файлов сохранено без изменений; переименованы только сами ZIP для удобных ссылок.

| Архив | Содержимое | Исходное имя |
| --- | --- | --- |
| [SPK-Raspisanie-source-1.3.0.zip](android/SPK-Raspisanie-source-1.3.0.zip) | Android-проект с versionName 1.3.0 в Gradle и AndroidManifest.xml | SPK-Raspisanie-source(1).zip |
| [spk-cloudflare-pages-archive.zip](web/spk-cloudflare-pages-archive.zip) | Снимок веб-приложения для Cloudflare Pages; номер версии не установлен | spk-cloudflare-pages(2).zip |

Это исторические снимки, а не актуальные исходники Android 1.11.0 или подтверждение текущей версии сайта. Публикация этих ZIP не запускает развёртывание сайта. Android-архив содержит встроенный снимок расписания и тестовый Excel; веб-архив — встроенный снимок расписания.

Контрольные суммы: [SHA256SUMS.txt](SHA256SUMS.txt). Для установки Android-приложения используйте APK из [GitHub Releases](https://github.com/MarkOfTheDevil/spk-schedule/releases).
