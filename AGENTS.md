# Репозиторий готовых APK

- Содержит оригинальные подписанные APK, описания и сценарии публикации. Android-исходники и ключ подписи хранятся отдельно.
- Для новой версии подготовьте release/ через tools/prepare_release.py, затем отправьте в main и проверьте GitHub Actions и опубликованный Release.
- Не публикуйте signing-private.zip, ключи, пароли, исходную Excel-таблицу или персональные данные расписания.
- Не перезаписывайте опубликованные APK под прежним номером.
- Исторические APK добавляйте в release-archive/v<версия>/ с настоящими номерами, не пересобирая современные исходники под старым номером.
- Проверки: python3 -m unittest discover -s tests -p test_release.py; проверка APK скриптом prepare_release.py --verify.
